Trabaja exclusivamente con mi segundo cerebro:

$SECOND_BRAIN

Ejecuta:

1. git status
2. git add .
3. git diff --cached --check
4. git diff --cached --name-only
5. Crea un commit con:
   "Actualizar segundo cerebro"
6. Ejecuta:
   git push

IMPORTANTE:

- NO añadas archivos que contengan credenciales.
- NO añadas API keys.
- NO añadas tokens.
- NO añadas contraseñas.
- NO añadas archivos .env.
- NO añadas claves privadas.
- Si detectas credenciales, NO hagas commit ni push.
- Si no hay cambios, informa que el segundo cerebro ya está actualizado.
