Mi segundo cerebro está ubicado en:
$SECOND_BRAIN

IMPORTANTE:
El directorio actual de OpenCode puede ser cualquier proyecto.
NO asumas que el directorio actual es mi segundo cerebro.

Cuando utilice /procesar-inbox, procesa:
$SECOND_BRAIN/00 Inbox/

No proceses automáticamente todo el vault.

Para cada elemento en Inbox:
1. Lee el contenido.
2. Identifica las ideas importantes.
3. Busca notas relacionadas.
4. Comprueba duplicados.
5. Determina su categoría.
6. Organiza la información.

Destino:
- Conocimiento permanente → $SECOND_BRAIN/01 Knowledge/
- Información de proyecto → $SECOND_BRAIN/02 Projects/
- Recursos → $SECOND_BRAIN/03 Resources/
- Información temporal → $SECOND_BRAIN/00 Inbox/ (si no se puede clasificar aún)

No elimines información importante.
No conviertas automáticamente todo en conocimiento permanente.
