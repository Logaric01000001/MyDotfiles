---
description: "Aplica un perfil de herramientas MCP"
agent: sc-build
---

Gestiona perfiles MCP: $ARGUMENTS

Sin argumentos, ejecuta `sc-kit mcp profile list`.
Con un nombre, ejecuta `sc-kit mcp profile apply '<perfil>'` y muestra qué servidores se activaron o desactivaron. No inventes servidores que no estén instalados.
